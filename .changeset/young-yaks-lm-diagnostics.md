Add a provenance-audited browser-owned `LifeCycleSavings` dataset and reusable `plot.lm` rendering
for the four standard default regression diagnostic panels, with flat, recursive, integration, and
unchanged-package evidence plus explicit Cook's-distance capability boundaries. Also admit
independently authored core-package example manifests through `utils::example()`, starting with a
browser-owned arrows demonstration that preserves reusable global side effects. Add the complete
independently published `Puromycin` table through the generic declarative datasets path, with exact
types, factor levels, values, dimensions, aggregates, and namespace identity. Add a reusable bounded
nonlinear least-squares and profile vertical slice for ordinary two-sided numeric formulas, plus
non-persistent `plot.default(mgp=)` validation. Unsupported algorithms, model-frame controls,
bounds, trace output, and wider profile semantics fail explicitly. Add an independently authored
core `stats::lm.influence` example resource that constructs the documented `lm.SR` side effect
through ordinary `lm` and `lm.influence` calls. Add the complete browser-owned `datasets::state`
family through one generic multi-object data resource, including names, abbreviations, area, compact
map centers, Census divisions and regions, and the historical `state.x77` matrix with exact flat,
recursive, and integration evidence. Add the complete fixed `datasets::sunspots` series through the
generic declarative data path, accept standard `xaxt` and `yaxt` controls in time-series plots, and
support fractional two-component coordinates in `window()`. Add the complete fixed
`datasets::EuStockMarkets` multivariate time series through the generic core data path, and isolate
trusted static data-topic initialization budgets so large resources cannot consume the budget of
unrelated topics while user evaluation limits remain unchanged. Support GNU R's optional Unix-epoch
origin for numeric `as.POSIXct()`, including storage and attribute preservation, reusable
character/Date/POSIXct/numeric origins, NA/NaN/infinity behavior, and exact recycling diagnostics.
Date and POSIXct axis methods now also recognize forwarded missing format promises without forcing
them, carrying the unchanged `sfsmisc` `p.ts` example to completion.
