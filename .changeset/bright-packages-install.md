Add deterministic build-time installation for pure-R source directories, tarballs, and CRAN-like
repositories, with dependency locks, version checks, immutable resources, virtual `system.file()`
paths, package identity lookup, Collate/platform/portable-encoding handling, repository digest
verification, and an unchanged external package proof.
