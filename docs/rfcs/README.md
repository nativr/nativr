# NativR RFCs

RFCs define compatibility and architecture contracts before their implementation becomes difficult
to change. An RFC can be **proposed**, **accepted**, or **implemented**. Acceptance records the
intended contract; it does not itself prove runtime compatibility.

| RFC                                              | Status      | Subject                                          |
| ------------------------------------------------ | ----------- | ------------------------------------------------ |
| [0001](0001-normative-compatibility-profiles.md) | implemented | Normative compatibility profiles                 |
| [0002](0002-recursive-oracle-v2.md)              | accepted    | Recursive GNU R oracle v2                        |
| [0003](0003-pure-r-package-corpus.md)            | accepted    | Pinned pure-R package corpus                     |
| 0004                                             | proposed    | Runtime capability decomposition                 |
| 0005                                             | proposed    | Object ownership and byte-accounted memory model |
| 0006                                             | proposed    | NativR Native ABI v1                             |
